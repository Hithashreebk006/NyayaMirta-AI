# Nyaya Mitra AI

Nyaya Mitra AI is an AI-powered legal assistance platform that converts complex court judgments into simple summaries, verified action plans, and multilingual voice explanations. Users can upload legal PDFs, receive AI-generated insights, understand important legal steps, and access chatbot guidance through an easy and user-friendly interface.

## Features

* AI-generated legal summaries
* PDF upload and analysis
* Multilingual voice support
* AI legal chatbot
* User-friendly dashboard

## Tech Stack

* React + Vite
* Tailwind CSS
* Python/Flask
* OpenAI API

## Objective

To make legal information simple, accessible, and understandable for everyone using Artificial Intelligence.
